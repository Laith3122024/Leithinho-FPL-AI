# Laithinho FPL AI V6.0

نسخة V6 تبدأ طبقة Machine Learning حقيقية.

- تدريب على بيانات Gameweek تاريخية.
- منع تسريب نقاط الجولة المستهدفة إلى Features عبر lag/rolling.
- Time-aware validation وMAE.
- Production model يتدرب على كل التاريخ المتاح.
- توقع نقاط اللاعب للجولة القادمة.
- دمج ML مع محرك Laithinho بدل الاعتماد الأعمى على نموذج واحد.
- في بداية الموسم: GW1 تستخدم كبيانات حديثة، والتاريخ السابق يعوض قلة العينة.
- عند توفر جولات جديدة في مصادر البيانات، يعاد بناء التدريب عند انتهاء cache.

ملاحظة: هذا ليس "تعلم ذاتي لحظي"؛ إعادة التدريب تتم عندما يعاد تحميل Dataset التاريخي. لتضمين GW الحالية في التدريب، يجب إضافة مصدر تاريخي للموسم الجاري بعد توفر نتائج الجولة.
