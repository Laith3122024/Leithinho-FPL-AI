# Laithinho FPL AI V6.4 — Match Brain

نسخة محسنة تركز على توقع المباراة القادمة أولًا ثم تحويل توقع المباراة إلى توقع نقاط اللاعب.

## أهم التغييرات
- Match Engine باستخدام Team Strengths مطبعة إلى متوسط الدوري.
- احتمالات الفوز/التعادل/الخسارة وClean Sheet مبنية على توزيع Poisson.
- توقع نقاط اللاعب يعتمد على xG الفريق، حصة اللاعب الهجومية، الدقائق المتوقعة، Clean Sheet، saves للحراس، التاريخ، ML، وقوة المواجهة.
- التاريخ السابق يستخدم لتثبيت عينة GW1 الصغيرة بدل الاعتماد على الجولة الماضية وحدها.
- إضافة ثقة التوقع وسقف النقاط.
- لا يوجد نموذج يضمن نقاطًا صحيحة؛ الهدف هو تحسين المعايرة والدقة عبر backtesting بعد كل GW.

## V6.4.1 — Ownership Intelligence
- استخدام `selected_by_percent` كطبقة قرار استراتيجية، وليس كبديل عن توقع النقاط.
- تصنيف اللاعبين إلى ركائز عالية الملكية، ملكية متوسطة، وDifferentials منخفضة الملكية.
- اللاعب عالي الملكية مع توقع قوي يظهر كخيار آمن نسبيًا، وليس "مضمونًا".
- اللاعب منخفض الملكية مع توقع قوي يظهر كـDifferential محتمل.
- إضافة درجة أمان الملكية ودرجة Differential داخل تحليل اللاعب والمقارنة.
- لا نرفع Expected Points للاعب لمجرد أن ملكيته عالية؛ الملكية تؤثر على طبيعة القرار والمخاطرة، بينما التوقع الرياضي يبقى المحور الأساسي.
