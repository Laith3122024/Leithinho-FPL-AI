# Laithinho FPL AI V6.3.1 — Match Intelligence

نسخة V6.3.1 تجعل **المباراة القادمة** محور توقع النقاط.

## الجديد
- محرك توقع للمباراة القادمة لكل فريق.
- تقدير أهداف الفريق (xG تقريبي) باستخدام قوة FPL الرسمية + Home/Away + FDR.
- احتمالات فوز/تعادل/خسارة.
- احتمالية Clean Sheet لكل طرف.
- احتمال تسجيل الفريق هدفين أو أكثر.
- ربط توقع المباراة بتوقع اللاعب.
- تقدير xG وxA للاعب في الجولة القادمة.
- Expected Points جديدة تجمع Match Model + ML + التاريخ/الفورمة.
- Ceiling تقديري للمباريات ذات السقف العالي.
- عرض جدول المباريات القادمة داخل واجهة الفريق.
- عرض تفاصيل المباراة القادمة داخل تحليل كل لاعب.

## ملاحظة
توقعات الأهداف والاحتمالات هي **نماذج تقديرية** وليست ضمانًا للنتيجة. بيانات السوق/المراهنات لم تدخل بعد كعامل محوري في V6.3.1؛ سيتم إدخالها لاحقًا كـmarket signal مساعد بعد بناء Match Model واختباره تاريخيًا.


## V6.3.1 إصلاح ML
- تثبيت ترتيب خصائص ML.
- تحويل مدخلات Imputer إلى NumPy لتجنب تعارض feature names/order.
- حماية Runtime fallback حتى لا يتوقف التطبيق إذا فشل ML.
- إعادة تسمية دالة التدريب لتجنب استخدام cache قديم من V6.3.
