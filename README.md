# Laithinho FPL AI V6.5 — 3 Strategy Engine

نسخة عربية من Laithinho FPL AI مخصصة لـ 2026/27.

## الجديد في V6.5
- ثلاث تشكيلات مستقلة للجولة القادمة:
  - 🟢 Safe / Template: استقرار وملكية عالية.
  - 🔵 Balanced: مزيج بين الأمان والـDifferentials.
  - 🔴 Differential: يرفع قيمة اللاعبين منخفضي الملكية فقط عندما تكون بياناتهم قوية.
- كل استراتيجية تبني فريقًا كاملًا من 15 لاعبًا مع قيود FPL نفسها.
- التشكيلة الأساسية تُختار من كل فريق على حدة مع احتمال البداية والدقائق المتوقعة.
- عرض الدكة لكل استراتيجية.
- عرض النقاط المتوقعة، التشكيلة، عدد الـDifferentials ومخاطرة القرار.
- الملكية لا تغيّر Expected Points؛ هي طبقة قرار استراتيجية فقط.
- اللاعب غير المتاح/الغائب طويلًا لا يدخل التشكيلة المثالية.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```
